# CStatic's Art Fight HTML Templates 
A GitHub mirror of all of the HTML templates I've made for [Art Fight](https://artfight.net/). Everything from my [Toyhou.se](https://toyhou.se/CStatic) should be here too. As always, these were made specifically for Art Fight and may not work on Toyhou.se or other sites. You are free to adapt, change, and translate any of my templates to suit your needs. 
## How to use this repository
Everything is sorted into folders with instructions on how to use them.

- Very Condensed Art Fight Character Box
- Art Fight Character Information Template
- Art Fight Global Permission Boxes
- D&D 5E-Inspired Art Fight Character Profile Template
